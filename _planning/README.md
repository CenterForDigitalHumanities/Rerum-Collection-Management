## Core Thesis

RCM is an annotation-driven, graph-native system for describing, relating, collecting, and publishing cultural heritage resources through evidence-based assertions. It should prefer linked, virtual collections over custodial duplication; JSON-LD over private data models; and non-destructive annotation over record mutation.
